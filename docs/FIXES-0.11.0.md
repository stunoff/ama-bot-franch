## Практические ограничения

Реальные ссылки на материалы, полномочия, календарь, получатели и расписания утверждает владелец. Банк/налоговый режим фиксируются по подтверждённым сведениям ответственными сотрудниками; интеграция с банком, ФНС или ЭДО не добавлена. Банковские данные вносит куратор, передачу подтверждает назначенный исполнитель. Произвольные программные сценарии через справочник не исполняются: действуют поддерживаемые поля и типы событий.

Живая приёмка Telegram/MAX, проверка прав в реальных группах, восстановление на сервере заказчика и критерии П01–П68 требуют фактических свидетельств. Автотесты и подмена HTTP их не заменяют.
