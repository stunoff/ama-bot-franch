Это технический набор, а не акт полной приёмки ТЗ. Внешние API транспорта в тестах подменены. Реальных токенов/чатов заказчика нет; живые Telegram/MAX, доставка в реальные CDN MAX и восстановление на инфраструктуре заказчика не испытаны. Все 68 функциональных сценариев сохранены в acceptance.csv со статусом «не пройден end-to-end». Нереализованные части перечислены в COVERAGE.md.

Особенности среды проверки: Docker использует vfs и ограниченный диск. Первая многослойная сборка исчерпала место; Dockerfile сокращён до небольшого числа слоёв. Завершённый отдельный тестовый MySQL-контейнер удалён после проверки пустой ama_test; его volume сохранён. Первый запуск миграции выявил права исходных файлов 0600/директорий 0700 в среде; Dockerfile исправлен: /app передаётся непривилегированному пользователю ama. Эти особенности не меняют конфигурацию сервиса заказчика.
