# Обновление 0.5.0 → 0.6.0

Сохраните `ama-upgrade-0.6.0.py` в корень работающего проекта рядом с `compose.yaml`. Сначала проверка без записи:

```bash
python3 ama-upgrade-0.6.0.py --check
```

Скрипт сверяет обновляемые файлы с 0.5.0. При локальных изменениях останавливается до записи. `.env`, Compose, Dockerfile и тома не заменяет. Старые исходники сохраняет в `backups/source-*`.

Остановите обработку, сохраните БД, затем примените исходники и миграцию. Проверяйте результат каждой команды:

```bash
docker compose stop api worker
umask 077
mkdir -p backups
docker compose exec -T mysql sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" exec mysqldump --single-transaction --routines --triggers -uroot ama' > backups/before-0.6.0.sql
python3 ama-upgrade-0.6.0.py --apply
docker compose build
docker compose run --rm --no-deps migrate
docker compose up -d api worker
docker compose exec api python -m ama.cli diagnostics
```

При ошибке резервной копии/миграции не продолжайте запуск. Файловый том дополнительно сохраняется вашим способом. Не используйте `down -v`: это удаляет данные.

Миграция `0006` добавляет семь таблиц пакетов, редакций, публикаций, обязательств, вопросов, подготовленных файлов и регулярных планов. Существующие работы, оплаты, SLA и информационные Broadcast не преобразуются. Прежние миграции 0001–0005 сохранены.

Перед первой публикацией настройте отдельное право `broadcast_permission`, назначенных ФП/кураторов, их роли и аккаунты, проверенные клиентские чаты, опубликованный маршрут сопровождения, календарь и окно уведомлений. Внутренний Telegram-чат должен поддерживать темы и разрешать боту их создание. Затем `/packets` → небольшой тестовый пакет → предпросмотр → подтверждение → проверка доставки, ознакомления и отдельной приёмки задания. Подробности: [BROADCASTS-0.6.0.md](BROADCASTS-0.6.0.md).

Это обновление не восстанавливает сетевую маршрутизацию Docker Desktop и внешний webhook. Если бот не получает `/start`, отдельно проверяйте доступность API/ngrok. Внутреннее здоровье:

```bash
docker compose exec -T api python -c 'import urllib.request; print(urllib.request.urlopen("http://127.0.0.1:8000/health", timeout=5).read().decode())'
```

Откат — согласованная версия исходников и восстановление проверенной копии БД/файлов. Автоматического удаления истории рассылок через downgrade нет.
