# Обновление 0.7.0 → 0.8.0

Сохраните `ama-upgrade-0.8.0.py` в корень работающего проекта рядом с `compose.yaml`. Сначала проверка без записи:

```bash
python3 ama-upgrade-0.8.0.py --check
```

Скрипт сверяет обновляемые файлы с 0.7.0. При локальных изменениях останавливается до записи. `.env`, Compose, Dockerfile и тома не заменяет. Старые исходники сохраняет в `backups/source-*`.

Остановите обработку, сохраните БД, затем примените исходники и миграцию. Проверяйте результат каждой команды:

```bash
docker compose stop api worker
umask 077
mkdir -p backups
docker compose exec -T mysql sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" exec mysqldump --single-transaction --routines --triggers -uroot ama' > backups/before-0.8.0.sql
python3 ama-upgrade-0.8.0.py --apply
docker compose build
docker compose run --rm --no-deps migrate
docker compose up -d api worker
docker compose exec api python -m ama.cli diagnostics
```

При ошибке резервной копии/миграции не продолжайте запуск. Файловый том дополнительно сохраняется вашим способом. Не используйте `down -v`: это удаляет данные.

Миграция `0008` добавляет `learning_tracks`, `learning_editions`, `material_uses`. Сохраняются прежние Training, даты, версии, цифровые результаты, оплаты и рассылки. Прежние миграции 0001–0007 не меняются. Историческим пользователям не создаётся фиктивное новое прохождение.

Перед назначениями проверьте активного ФП/аккаунт, его основной проверенный клиентский чат, опубликованные календарь и маршрут сопровождения с действующим куратором, согласованное окно уведомлений. Владелец материалов заполняет реальные URL и подтверждает содержание/права. Опубликованный КЦ — отдельный курс `call_center` по применимости предприятия.

После установки: `/learning` → персональный маршрут ФП; та же команда в сопровождении → прогресс/назначение куратора. Проверьте границу раздела и явное завершение, материалы, сохранение места, существенное обновление и замену ссылки. Тестирование таймеров в боевой БД не выполняйте изменением системных часов. Руководство: [LEARNING-0.8.0.md](LEARNING-0.8.0.md).

Реальные ссылки ещё не предоставлены: реестр из 85 требований не является опубликованной базой. Владелец должен заполнить и проверить их; программа не подставляет вымышленные значения.

Это обновление не восстанавливает сетевую маршрутизацию Docker Desktop и внешний webhook. Если бот не получает `/start`, отдельно проверяйте доступность API/ngrok. Внутреннее здоровье:

```bash
docker compose exec -T api python -c 'import urllib.request; print(urllib.request.urlopen("http://127.0.0.1:8000/health", timeout=5).read().decode())'
```

Откат — согласованная версия исходников и восстановление проверенной копии БД/файлов. Автоматического удаления истории ознакомления через downgrade нет.
