# Обновление до 0.9.0

Полный архив содержит пункты 7 и 8. Для текущей 0.8.0 используйте `ama-upgrade-0.9.0.py`. Для 0.7.0 есть объединённое обновление `ama-upgrade-0.7.0-to-0.9.0.py`: отдельно устанавливать 0.8.0 не нужно. Выполняйте из корня проекта рядом с `compose.yaml`. Ниже имя файла для 0.8.0; на 0.7.0 подставьте имя объединённого скрипта.

```bash
python3 ama-upgrade-0.9.0.py --check
```

Проверка сверяет исходники с соответствующей базовой версией. При локальных изменениях скрипт останавливается **до записи**; сравните изменённые файлы. `.env`, Compose, Dockerfile, БД и файловые тома он не заменяет. Старые исходники сохраняются в `backups/source-*`.

Остановите обработку, сохраните БД и файловый том; проверяйте результат каждой команды:

```bash
docker compose stop api worker
umask 077
mkdir -p backups
docker compose exec -T mysql sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" exec mysqldump --single-transaction --routines --triggers -uroot ama' > backups/before-0.9.0.sql
python3 ama-upgrade-0.9.0.py --apply
docker compose build
docker compose run --rm --no-deps migrate
docker compose up -d api worker
docker compose exec api python -m ama.cli diagnostics
```

Команда копирования предполагает БД `ama`; при другом имени подставьте своё. При ошибке копии, сборки или миграции не продолжайте запуск. Файловый том сохраните вашим способом. `down -v` удаляет данные, не используйте его для обновления.

Миграция 0009 добавляет шесть финансовых таблиц. Миграции 0001–0008 не меняются, действующие документы, обучение, работы, оплаты и рассылки сохраняются. История автоматически не преобразуется в новые обязательства или фиктивные оплаты. С 0.7.0 также применяется 0008 для персонального ознакомления.

После запуска настройте реальные роли, маршруты, утверждённые реквизиты и договорные правила. `/finance` открывает профильную очередь; клиент видит свои допуслуги. Пройдите проверочный договор без реальной отправки юридических документов, отдельно согласуйте ввод начальных остатков и исторических платежей. Подробности: FINANCE-0.9.0.md. Пункт 7: LEARNING-0.8.0.md и таблица материалов; реальные ссылки пока не предоставлены.

Это обновление не исправляет внешнюю маршрутизацию Docker/ngrok/webhook. При необходимости отдельно проверьте доступность API с хоста. Откат требует согласованного восстановления исходников, БД и файловой копии; автоматическое удаление финансовой истории не предусмотрено.
